# Cashier Skate
تطبيق ويب موبايل أولي يعمل محليًا، مخصص لمراجعة شغل الكاشير.

## التشغيل
افتح `index.html` في المتصفح.

## المزايا
- تسجيل تذاكر الاسكيت 140ج، دلافين/سنادات 30ج، عربيات بضائع 35ج، اشتراك 850ج.
- مراجعة أرقام التذاكر (أول رقم/آخر رقم) ومقارنتها بالمبيعات.
- عد فئات النقدية 200/100/50/20/10/5.
- مقارنة إجمالي المبيعات بالنقدية الفعلية.
- تنبيه عند كل 10 دلافين مع صوت/اهتزاز عند دعم الجهاز.
- سجل أيام محفوظ محليًا.
- إعدادات الأسعار والصوت والاهتزاز والمؤثرات.
